# homebrew-tap

Official Homebrew tap for [Koality-Assured](https://github.com/Koality-Assured) developer tooling and domain harnesses.

## Installation

Add this tap to Homebrew:

```bash
brew tap Koality-Assured/tap
```

Install `harness`:

```bash
brew install harness
```

Or install in a single command:

```bash
brew install Koality-Assured/tap/harness
```

## Available Formulae

| Formula | Description |
| :--- | :--- |
| [`harness`](Formula/harness.rb) | Unified Harness CLI Control Plane for domain harnesses and spokes |
